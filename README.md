# Пригожин: путь к власти

Разрабатываемый форк для платформы **Pax Universe 0.32.11**. Вариант `game` сохраняет базовые карту, экономику и войну; профиль сохранений отдельный. Требуется установленная лицензированная Pax Universe.

Авторский сюжет начинается в России **1 сентября 2018 года**. Игрок — предприниматель Евгений Пригожин. Российские государственные учреждения сохраняют власть, НФВ только формируется, исходы альтернативной истории не предопределены. Полный сюжет: [docs/STORY_RU.md](docs/STORY_RU.md).

## Статус

Это версия для закрытого авторского тестирования, **не законченная игра**. Актуальный номер версии находится в [mod.json](mod.json).

В коде есть настоящие карточки отрядов ЧВК, очередь найма с ограниченным резервом, наземные маршруты, внутренние задачи командиров и базовый авиачартер. Добавлены закупочные договоры через систему снабжения движка и отображение действующих предприятий с последним рассчитанным недельным результатом.

Полный авторский старт, боевые договоры заказчиков, общий учёт затрат задач и политическая система остаются в разработке. Успешная проверка файлов не подтверждает работу этих цепочек в партии.

## Структура

- `main.gd` — вход PaxMod, состояние и подключения.
- `systems/` — механики и адаптеры к движку.
- `ui/` — штаб, снабжение и предприятия.
- `data/` — патчи, правила и локализации ru/en.
- `presets/` — вариант сценария «Пригожин — Россия 2018» за частное лицо.

Сценарий пока использует стандартную анкету. Начальные активы и размещение частной резиденции в Туношне требуют доведения. Сохранения старого мода автоматически не мигрируются.

## Установка и проверка

Форк устанавливается через раздел **«Форки»** лаунчера; платформа проверяет авторскую регистрацию или право доступа. Его не следует включать как обычный мод. Внешние моды автоматически не принимаются.

Проверка отдельным процессом из папки игры:

```text
PaxUniverse.exe --headless -- --check-mods prigozhin_fork
```

В основной игре нельзя отключать форк посреди активной авиаперевозки: записи перевозимых отрядов хранятся в его состоянии. Сначала завершите рейс.

В этот репозиторий не включены сохранения, ключи, настройки учётных записей, журналы и внутренние записи предыдущих сеансов. Исходники и исполняемые файлы самой Pax Universe также не включены.
